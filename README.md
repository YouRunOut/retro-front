# Retrowave Radio

A web-based music player for retrowave, synthwave, and retro-inspired electronic music.

**Live demo:** https://retrowave-radio.ru/

## Overview

Retrowave Radio is a single-page web application built with Vue 3 and TypeScript. It provides an audio streaming experience wrapped in a retro-futuristic interface inspired by cassette players, CRT displays, and VHS aesthetics.

The project focuses on audio playback, API integration, interactive player controls, and visual presentation.

## Features

- **Audio streaming** — playback of online radio streams using HLS.
- **Track metadata** — display of currently playing tracks and track information.
- **Playback controls** — volume adjustment and persistent user preferences.
- **Retro-inspired UI** — cassette-themed player interface, CRT/VHS effects, vignette, and animated visual elements.
- **Backend integration** — fetching track data and submitting ratings through a REST API.
- **Analytics** — Yandex Metrica integration.

## Tech Stack

- Vue 3
- TypeScript
- Vite
- HLS.js
- REST API
- HTML5 Audio
- CSS3
